# M Project

سیستمعامل شخصی برای برنامهنویس + VPN داخلی

## درباره
M یک سیستمعامل سبک بر پایه Linux است که برای برنامهنویسها طراحی شده.
شامل VPN داخلی برای دور زدن تحریمهاست.

## ساختار
- `os/`  سیستمعامل
- `mouse/`  موس M-Mouse
- `docs/`  مستندات
- `scripts/`  اسکریپتها
- `branding/`  هویت بصری
- `tests/`  تستها
